# CommitCity v0.1

The first public version: type a GitHub username and walk around its city.

## What's in it

- **Your city at `/u/<username>`.** Every public repository a user or organization owns becomes a building on its own lot. The oldest repositories sit in the center and newer ones spiral outward, so adding a repository never moves the others.
- **Buildings from your data.** The primary language picks the building family, stars pick the size of the lot it covers, and the commit count picks how tall it grows. Archived repositories look abandoned, and forks are a size smaller.
- **Explore it.** Drag to pan, scroll or pinch to zoom, rotate in four directions, and click a building to see its repository. The URL keeps the rotation and the selected building, so a shared link opens the same view.
- **Pixel art.** Ground, roads, trees and two building families (brick and modern), drawn on a 32 × 16 isometric grid with the Resurrect 64 palette.
- **Same URL, same city.** Generation is deterministic, and the GitHub data is cached for a day, so everyone who opens a link sees the same city.

## Known limits

- Up to 1,000 repositories per account; above 300 they are all individual buildings for now (aggregate lots come later).
- Two building families so far; other languages borrow their look.
- No social preview image yet.

## For contributors

- Artists can add buildings as a folder with PNGs and a manifest, with no code. `pnpm validate-assets` checks them (`docs/ART_DIRECTION.md`).
- Running it locally and deploying: `CONTRIBUTING.md` and `docs/DEPLOYMENT.md`.
